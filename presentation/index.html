06 · Aqlli baholash

Imtihonchi AI o'zbek tilida tushuntiradi

  • Og'zaki nutqqa moslashgan — katta harf va tinish belgilari xato hisoblanmaydi.
  • Missiya bajarilganini tekshiradi (to'g'ri mahsulot va miqdor).
  • Real grammatik xatolar: "I wants", "two apple" → to'g'ri varianti bilan.
  • Natija qat'iy JSON formatda: score, completed, mistakes, feedback.

🎉 Vazifa Bajarildi!

Chiqish oldidan til tahlili hisoboti:

Bajarilish darajasi:88%
Xatolar va to'g'rilash:
Siz aytdingiz: 'give me two apple' ➔ To'g'risi: 'Could I have two apples, please?' (Izoh: ko'plikda -s qo'shiladi, so'rov muloyimroq bo'ladi)
Umumiy xulosa: Vazifani a'lo darajada bajardingiz! Muloyim iboralardan foydalanishda davom eting.

10 · Qiyinchiliklar

Muammolar va yechimlar

🎤

STT xatolari

Mikrofon matnida katta harf va tinish belgisi yo'q. Yechim: baholash promptida ularni e'tiborsiz qoldirish qoidasi.

🧾

LLM javob formati

Model ba'zan markdown qaytaradi. Yechim: JSON-only prompt, ```json tozalash va xavfsiz fallback.

📷

Kamera va o'tishlar

Ichkari/tashqari o'tishda kamera chalkashardi. Yechim: har joy uchun alohida theta/phi/radius.

📦

Og'ir modellar

GLB fayllar jami ~490 MB. Reja: Draco / Meshopt siqish, LOD va lazy-loading.

🔐

API kalit xavfsizligi

Kalit hozir frontendda. Reja: serverless proxy (backend) orqali so'rov yuborish.

🌐

Brauzer mosligi

Web Speech API asosan Chrome/Edge'da. Yechim: matnli chat zaxira varianti mavjud.
