High Speaking Anxiety

06 · Autonomous AI Agents

Persona-Driven Conversational Intelligence

🎭

Specialized Domain Vocabularies

Each agent is bound to a tailored system prompt specifying domain jargon (financial terms for David, medical triage for Sarah, hospitality etiquette for Emma).

💬

Conversational Pacing & Length

Prompts strictly restrict replies to 1–2 natural spoken sentences without quotation marks or markdown, ensuring realistic verbal conversation rhythms.

🔄

Rolling Memory Buffer

Agents maintain a rolling 4-turn message memory buffer, remembering preceding context while keeping token overhead and latency strictly minimized.

// Dynamic Persona Prompt Injection (App.jsx)
const systemPrompt =
  npc === "Bank Employee" ? `You are David, a polite bank officer at Village Bank. Help with accounts, wire transfers, cards. 1-2 short sentences.`

  : `You are Mia, a friendly cafe barista in a 3D village. Help the user order drinks and pastries naturally.`;

09 · Automated Assessment

Speech-Aware Examiner AI

  • Disregards STT Artifacts: Microphones omit capital letters and periods. The rubric explicitly ignores casing, preventing false negatives.
  • Task Goal Verification: Checks that requested items, quantities, and questions were communicated accurately.
  • Real Spoken Grammar Diagnosis: Catches count/mass errors ("two apple"), agreement slips ("I wants"), and polite modal forms.
  • Structured JSON Output: Deterministic schema with score (0–100), completion status, and native explanations.

12 · Engineering Highlights

Key Technical Challenges & Solutions

🎙️

STT Transcription Quirks

Challenge: Microphones omit capitalization; standard LLMs penalize lowercase text as grammatical errors.
Solution: Custom evaluation rubric explicitly strips punctuation/casing sensitivity.

🛡️

LLM Markdown Hallucination

Challenge: Cloud LLMs sometimes wrap JSON in markdown backticks, breaking JSON.parse().
Solution: Multi-pass regex sanitization and schema-guaranteed fallback object generation.

📷

Camera Collision & Lerping

Challenge: Moving between open roads and compact facility interiors caused camera clipping.
Solution: Contextual spherical coordinate lerping (theta/phi/radius) tuned per building.

📦

Asset Weight & Frame Rates

Challenge: 15+ GLB models risked high memory footprint and WebGL frame drops.
Solution: Geometric instancing, shadow-bias tuning to prevent acne, and React Suspense loading.

🧱

Boundary Collisions (AABB)

Challenge: Complex 3D mesh collisions caused physics stutter.
Solution: Configured lightweight 2D AABB bounding boxes (VILLAGE_BUILDINGS) for smooth 60 FPS.

🗣️

Speech-Avatar Sync

Challenge: Syncing synthetic voice with 3D character gestures.
Solution: Reactive isTalking hooks bound to TTS onstart and onend audio lifecycle events.
